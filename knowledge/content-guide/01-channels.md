# 01. 채널별 구조

## 1. 상세페이지 (Qoo10) — 12장

세 보고서의 구매 전환 흐름(토너 7단계 · 에센스 7단계 · 마데카21 8단계)은 공통으로 **훅 → 공감 → 해결(루틴) → 차별점 → 제형 → 증거 → 사용법 → 안심 → 정보**다. 이를 약기법에 맞게 12장으로 고정한다 (팀 결정: 단품은 12장, 디자이너가 늘려도 된다).

| # | key | 장면 | 쓰는 법 |
| --- | --- | --- | --- |
| 1 | hook | 훅 (시즌·프로모션) | 시즌·사용감 감성 카피 2줄. 「季節の変わり目に、〜」 같은 구조. 1위 배지·판매량 대신 문장으로 멈추게 한다 |
| 2 | proof | 사회적 증거 | **근거 자료가 입력에 있을 때만.** 없으면 빈 칸(`needs_evidence: true`) |
| 3 | concern | 고민 제기 | 건조·당김·메이크업 들뜸만. 질환·민감 표현 금지 |
| 4 | routine | 루틴 제안 | 같은 라인 **출시 제품만** (스킨 → 에센스). 세트 구매로 잇는다 |
| 5 | hero | 제품 히어로 | 제품명 + 한 줄 가치 |
| 6 | points | 특장점 3가지 | ①②③. 리뷰 소구점을 효능 범위 안의 말로 |
| 7 | ingredient | 성분 (최대 4분할) | 전성분에 있는 성분만, 배합 목적 각주 (03 참고) |
| 8 | texture | 제형 | 감각어 1~2개 (02 참고) |
| 9 | howto | 사용법 | 순서·양·시간대 |
| 10 | review | 리뷰 말풍선 | 리뷰가 있는 제품만(`needs_reviews: true`). 별점은 실제 수치일 때만 |
| 11 | lineup | 라인업 | 출시 제품 비교 |
| 12 | info | 전성분 · 제조원 | 전성분 · 용량 · 사용상 주의 · 제조판매원 안내 |

- 개발 중(`developing`) 제품은 상세페이지를 만들지 않는다.
- 화면 리듬(마데카21 보고서): 1~3장은 밀도 높게, 4~9장은 여백 크게(제품·제형에 집중), 11~12장은 표로 정리.
- 언어 비율: **일본어 85% · 영어 15%**. 영어는 브랜드 로고, 섹션 머리말(MAIN INGREDIENT · TEXTURE · HOW TO USE), 성분 약어 정도만. 설득 문장·사용법·주의사항은 모두 일본어.
- 제품 종류별: **스킨**은 빠른 설득(물 제형 표면장력 컷), **에센스**는 단가가 높아 설득 구간이 길고 제형(드롭·롤링)과 루틴을 강조한다.

### 상품명 (큐텐 타이틀) — 제목 단계에서 만든다

큐텐 검색 결과·랭킹·상품 페이지 맨 위에 나오는 이름이다. 일본 소비자는 가타카나와 영문으로 나눠 검색하므로 **브랜드는 둘 다** 넣는다 (팀 기획 가이드 추가사항 2026-10-24).

**형식**

`【公式】リーフアンド(Leaf&) {product_ja} {종류} {용량} / 효능・효능・효능`

| 순서 | 넣는 것 | 예 |
| --- | --- | --- |
| 1 | 【묶음】 사실만 | 【公式】 (항상) · 【メガ割】【NEW】는 실제 행사·출시 때만 |
| 2 | 브랜드 가타카나(영문) | リーフアンド(Leaf&) |
| 3 | 일본어 제품명 · 종류 · 용량 | リーフ＆デュー ディープスキン 化粧水 200ml / リーフ＆デュー コアエッセンス 美容液 50ml |
| 4 | 「/」 뒤에 효능 3개 (「・」로 구분) | 保湿・うるおい・キメ |

- 효능 3개는 **리뷰 소구점 + 시장 분석 검색어**에서 고르고, 효능 범위 안의 말만 쓴다 (保湿 · うるおい · キメ · 乾燥対策 · さっぱり · しっとり). 랭킹 예시의 「鎮静・毛穴・赤み」「導入液・ハリ」는 일반 화장품 효능 범위를 넘거나 근거가 필요해서 쓰지 않는다.
- 앞쪽(브랜드~용량)에 제품을 알아볼 정보, 뒤쪽에 키워드를 둔다. 검색 결과에서 뒤가 잘려도 제품은 알아볼 수 있게.

**넣지 않는 것** (랭킹 상품명에 흔하지만 근거·효능 범위 문제)

| 랭킹 상품명 예 | 이유 |
| --- | --- |
| 【化粧水1位】 【レビュー14万件突破】 【BEST】 | 근거 없는 순위·수치 (F8.2, 景品表示法). 근거 자료가 있으면 기간·출처와 함께만 |
| ニキビ · 肌荒れ · ゆらぎ肌 · 敏感肌 | 질환·민감 암시 (E8, F7.5) |
| シミ · 透明感 · トンアップ · 毛穴 · インナードライ 3秒水分チャージ | 미백·모공 효능, 즉효 (일반 화장품 효능 범위 밖, F9) |
| 성분명 + 함량 (ツボクサエキス95% · 純度99％ · 3,000PPM) | 특기 성분은 배합 목적이 필요하고 함량 강조는 근거가 필요 (E24, F5.5) |
| 【GIFT付】 | 실제 사은품 행사가 있을 때만 |
| 연예인 이름 · 「◯◯ PICK」 | 계약·권리 확인 전에는 쓰지 않음 |
| 다른 브랜드 이름 | 다른 회사 자산 |

### 대표 이미지 (정사각형 1:1) — 5장

상품 페이지 맨 위에서 옆으로 넘기는 사진. **첫 장은 검색 결과 목록의 썸네일**이라 가장 중요하다.

| 장 | 역할 | 규칙 |
| --- | --- | --- |
| 1 | 대표 (검색 썸네일) | 1:1, 좌우 여백 없이 꽉 채움. 제품 단독 정면, 단색 배경, 제품이 화면의 70~80%. 맨 아래 띠에 한 줄 카피(효능 범위 안) 가능. [+Gift] 배지는 실제 사은품 행사 때만. 순위·할인·「No.1」·「累計」 금지. 모델·다른 회사 제품·연구소 연출 금지 |
| 2 | 제품 + 용량·종류 | 용량(ml)·종류(化粧水) 표기 |
| 3 | 제형 | 물방울 또는 손등에 펴 바른 컷 |
| 4 | 핵심 포인트 3가지 | 아이콘 + 짧은 문구 (효능 범위 안) |
| 5 | 사용법 · 루틴 | 스킨 → 에센스 |

## 2. 인스타그램

| 항목 | 규칙 |
| --- | --- |
| 역할 | 신뢰·학습 (왜 사야 하는가를 설득) |
| 블록 순서 | `caption` → `slide1` … `slideN` (N = 사진 장수 1~5) |
| 캡션 구조 | 첫 줄 훅 → 본문 `POINT 💡 ①②③` → 행동 유도(`▼ 詳しくはプロフィールのリンクから〜`) → 약기법 각주 |
| 캡션 길이 | 8~15줄. **더보기 전 첫 2줄**에 소구점 |
| 줄바꿈 | 문장마다 줄바꿈, 내용이 바뀔 때 빈 줄 |
| 슬라이드 | 4:5 세로. 역할: 1 커버(2줄 이내) → 2 고민 → 3 제형 → 4 사용법 → 5 마무리(행동 유도). 장수가 적으면 앞에서부터 |
| 사진 비중 | 제품 35 · 제형 30 · 피부 사용 25 · 라이프스타일 10 미만 → 제형 컷 1장은 꼭 |
| 커버 표기 | 영문 브랜드 크게 + 위에 작은 가타카나 읽는 법 (예: 「リーフアンド」 / Leaf& Dew) |
| 캡션 첫 줄 | 훅 문장 다음 줄에 【Leaf& / リーフアンド】+ 일본어 제품명. 「＼〜／」는 쓰지 않음 (팀 결정) |
| 해시태그 | **5개** = 브랜드 2(영문·가타카나 한 쌍 #LeafAnd #リーフアンド) · 성분·제형 1 · 고민·트렌드 1 · 검색어 1 (검색어 태그는 코드가 붙인다 → AI는 4개) (팀 결정) |
| 링크 | 프로필 링크로 안내 |
| 협찬 게시물 | 첫 줄 맨 앞에 【PR】 |

## 3. X

| 항목 | 규칙 |
| --- | --- |
| 역할 | 속도·확산 (지금 알리기) |
| 블록 순서 | `post` → `image` |
| 구조 | 헤드라인 → 핵심 1~2줄 → 링크 안내 (「商品ページはリプ欄から👇」) |
| 글자 수 | 해시태그 포함 **130자 이내** (한도 140) |
| 해시태그 | **2개** = 브랜드 1 · 캠페인/제품 1 (3개를 넘으면 노출이 줄어든다) |
| 이미지 | 16:9 (1200×675) 1장 |
| 링크 | 본문에 넣지 않고 첫 답글 |
| 각주 | 각주가 필요한 표현(浸透 등)은 피하고 짧게 |
| 캠페인 (フォロー＆リポスト) | 당첨 인원 · 응모 자격(日本国内在住) · 마감 · DM 통보를 모두 적을 수 있을 때만. **지금은 만들지 않는다** |

## 4. 배너

- 가로형 1종. 블록 순서 `copy` → `sub`.
- 메인 카피 15자 안팎, 효능 범위 안의 짧은 문장. 서브는 제품명.
- 이모지 · 해시태그 없음.
