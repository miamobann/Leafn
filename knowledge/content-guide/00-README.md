# 콘텐츠 제작 규칙 (콘텐츠 제작 가이드 AI용)

광고 검토(TAB 3) 콘텐츠 제작 가이드의 생성 프롬프트(`apps/web/prompts/content-guide-*.md`)에 넣는 채널·말투 규칙이다. 약기법 판단 기준은 이 폴더가 아니라 `knowledge/yakkiho/`에 있고, 프롬프트에 함께 넣는다.

## 우선순위

**약기법(`knowledge/yakkiho/`) > 이 폴더의 채널 규칙 > 담당자의 「강조할 방향」**

이 폴더의 규칙이 약기법과 부딪히면 약기법을 따른다. 담당자가 적은 방향은 참고로만 반영한다.

## 출처

| 출처 | 쓴 곳 |
| --- | --- |
| 팀이 받은 분석 보고서 4개: Qoo10 1위 스킨·토너 상세페이지 비교, Qoo10 1위 에센스·세럼 상세페이지 비교, 마데카21 Qoo10 상세페이지 리버스 엔지니어링, 일본 K-뷰티 Instagram vs X 운영 전략 | 01 채널 규칙, 02 말투, 04 촬영 |
| 팀 결정 (2026-10-22~24, TAB 3 담당 · 회의) | 해시태그 개수, 장식 기호 금지, 게시물 종류, 상세페이지 12장 등 — 각 항목에 「팀 결정」 표시 |
| `knowledge/yakkiho/` | 03 콘텐츠용 약기법 점검 |

## 원칙

- **다른 회사의 이름·제품명·문구·색·캐릭터는 넣지 않는다.** 보고서의 구조(순서·역할)만 가져오고 문장은 새로 쓴다.
- **보고서 사례 중 약기법에 걸리는 것은 뺐다** (랭킹 1위 배지, 누적 판매량, 기간 효과, 연구소 연출 등). 뺀 목록은 03에 있다.
- 숫자(글자 수·장 수·비율)는 화면 코드(`apps/web/app/(internal)/(dashboard)/ad-check/_lib/`)와 같게 유지한다. 바꿀 때는 둘 다 고친다.
