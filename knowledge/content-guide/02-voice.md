# 02. 말투 · 브랜드

## 브랜드와 계정

| 항목 | 값 |
| --- | --- |
| 브랜드 | Leaf& (리프앤드) |
| 인스타그램 | `leafand.jp` (Leaf& Japan 公式) |
| X | `@leafand_jp` (Leaf& 公式) |
| Qoo10 | 「Leaf& 公式ショップ」 |
| 제품명 | 영어 `{product}` · 일본어 `{product_ja}` 자리로 둔다. 코드가 실제 이름으로 바꾼다. **큐텐 상품명 줄은 일본어 이름**, 본문 제품 정보에는 영어 이름도 함께 |
| 일본어 제품명 | 리프앤드 듀 딥스킨 → リーフ＆デュー ディープスキン · 코어 에센스 → リーフ＆デュー コアエッセンス · (개발 중) ティーピュアスキン · マイルドスキン |

## 채널별 말투

| 채널 | 말투 | 이모지 |
| --- | --- | --- |
| 상세페이지 · 배너 | 차분하고 신뢰감 있게 (です·ます 또는 체언 종지) | 없음 |
| 인스타그램 | 친근하게 말을 거는 말투 (〜してね · 〜しませんか) | 캡션 전체 4~8개, 제품 톤에 맞게 (보습 💧🩵🫧 · 계절 ❄️🌸) |
| X | 짧고 가볍게 | 1~2개 |

## 장식 기호 금지 (팀 결정)

보고서 사례에 많은 「＼〜／」 「＼新登場／」처럼 문장을 감싸는 장식 기호는 쓰지 않는다.

## 첫 줄 스타일

| 스타일 | 예 | 어울리는 곳 |
| --- | --- | --- |
| 선언형 (기본) | 「乾燥が気になる季節に。」 | 모든 채널 |
| 공지형 | 「【NEW】{product}」 「【特報】」 「【お知らせ】」 | 신제품 · 행사 알림 (X에 잘 맞음) |
| 질문형 | 「スキンケアに迷っていませんか？」 | 인스타 · 상세 고민 장면 |
| 감성 스토리 | 짧은 장면 묘사 한두 문장 | 인스타 · 시즌 게시물 |

## 감각어 (사용감 표현만)

효능을 약속하는 말이 아니라 **바를 때의 느낌**을 그리는 말로만 쓴다.

| 제품 | 감각어 |
| --- | --- |
| 스킨 (化粧水) | さっぱり · しっとり · すーっと |
| 에센스 (美容液) | もちもち · ぷるぷる · つるん · とろみ |

## 게시물 종류

| 종류 | 쓰는 법 |
| --- | --- |
| 일반 | 제품 소개. 리뷰 소구점 중심 |
| 메가와리·세일 | 루틴(스킨 → 에센스) 세트 제안. 행사명·기간은 입력의 `[행사]`에 있을 때만. 할인율·「最安値」·「今だけ」 금지, 세일 내용은 「Qoo10公式ページをご確認ください」로 |
| 시즌 | 계절 고민(겨울 건조 등)과 소구점을 잇는다. 효능 범위 문구 그대로 쓰기 좋다 (「乾燥による肌あれを防ぐ」) |
| (보류) 신제품·런칭 기념, 구매 혜택 | 아직 만들지 않는다 |

## 강조할 방향 (담당자 입력)

- 담당자가 적은 한 줄(50자 이내)은 분위기 · 강조점 · 대상 같은 **방향 참고**로만 반영한다.
- 약기법이나 이 규칙과 부딪히면 반영하지 않고, 왜 반영하지 않았는지 추천 이유에 적는다.
