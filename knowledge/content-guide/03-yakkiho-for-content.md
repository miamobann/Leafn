# 03. 콘텐츠에서 자주 걸리는 약기법 표현

판단의 근거는 `knowledge/yakkiho/`이다. 이 문서는 콘텐츠를 **만들 때** 먼저 피하도록 자주 나오는 경우만 모았다. 항목 번호(E·F·〔表3〕)는 `knowledge/yakkiho/`의 번호다.

## 바꿔 쓰기

| 이런 표현은 | 이렇게 바꾼다 | 근거 |
| --- | --- | --- |
| 肌の奥まで / 浸透 (각주 없음) | 角質層まで* + 각주 「*浸透：角質層まで」 | E3 |
| 성분명만 내세움 (ヒアルロン酸配合) | 배합 목적 각주 「*ヒアルロン酸Na：保湿成分」. 전성분에 없는 성분은 쓰지 않음 | F5.5, E24 |
| Qoo10ランキング1位 / 累計◯万本 / 口コミ◯件 (근거 없음) | 쓰지 않음. 칸은 `needs_evidence: true` | F8.2, 景品表示法 |
| 7日で / 1回で実感 / 翌朝 | 毎日のうるおいケアに | F9, E23 |
| 肌再生 / 治る / 改善 / 毛穴縮小 / 美白 | 효능 범위 표현 (肌を整える · キメを整える · 乾燥による小ジワを目立たなくする*) | E8, 〔表3〕 |
| チクチクは効いているサイン | 쓰지 않음 (자극을 효과로 포장) | F7.5, E8 |
| 低刺激 / 敏感肌にも / パッチテスト済み (근거 없음) | 쓰지 않음. 근거가 있으면 각주 「すべての方に刺激が起こらないということではありません」 | F7.5 |
| 여드름·붉은기·홍조·「ゆらぎ肌」·「インナードライ改善」 | 건조 · 피부결 · 당김 · 메이크업 들뜸 | E8 |
| 의사·연구원·비커·플라스크·현미경 연출 | 쓰지 않음. 제품 · 제형 · 사용 장면으로 | E14, F11 |
| 今だけ / 最安値 / ◯%OFF / 1+1 (근거 없음) | 「セール内容はQoo10公式ページをご確認ください」 | 景品表示法 |
| 경품 캠페인에서 당첨 인원·자격·마감 누락 | 입력에 셋 다 있을 때만 캠페인 문구 | 景品表示法 |
| 협찬 게시물에서 PR 표기 없음 | 첫 줄 맨 앞에 【PR】 | 스텔스 마케팅 규제 (05) |

## 보고서 사례에서 뺀 것

분석 보고서에는 있지만 그대로 쓰면 걸려서 규칙에서 뺀 것들이다.

| 보고서 사례 | 뺀 이유 |
| --- | --- |
| 랭킹 1위·2관왕 배지, 누적 1,000만 병, 9,999건 후기, 평점 4.8 | 근거 없는 수치·순위 (F8.2, 景品表示法) |
| 「7日で」 「1回で実感」 「毛穴 -38%」, 임상 수치 | 기간·즉효·수치 보증 (F9, E22, E23) |
| 「肌再生」 「チクチクは効いているサイン」 「肌の奥まで」 | 의약품적 표현·작용 부위 (E8, E3) |
| 비커·플라스크·연구원 가운·현미경·피부과 시술 연출 | 권위 연출 (E14, F11) |
| 여드름·홍조·붉은기 접사, 「ゆらぎ肌」 | 질환·민감 암시 (E8) |
| 「피부 저자극 테스트 완료」 도장 | 근거 + 각주가 있을 때만 (F7.5) |
| 「美白」 「毛穴縮小」 | 일반 화장품 효능 범위 밖 |
| 메가와리 1+1 · 100% 증정 | 실제 행사 내용이 입력에 있을 때만 (景品表示法) |
