# 약기법 기준 자료 (발췌본)

광고 검토(TAB 3) 판정 프롬프트(`apps/web/prompts/ad-check.v*.md`)에 넣는 기준 자료다. CLAUDE.md 7장 4번: MVP에서는 이 폴더 내용을 프롬프트에 통째로 넣는다.

## 원칙

- **필요한 부분만 발췌한다.** 원본 전체(가이드라인 58쪽, 법 전문)는 프롬프트에 넣기엔 너무 크고, AI가 중요한 부분을 놓치기 쉽다.
- **원문 그대로 옮긴다.** 요약하거나 고쳐 쓰지 않는다(05 스테마는 이미지형 PDF라 사람이 읽어 옮긴 요약·발췌). 각 항목에 원본 쪽수를 붙여 대조할 수 있게 한다.
- **원본 파일은 저장소에 올리지 않는다.** PDF·XML 원본은 각자 컴퓨터에 두고, 아래 출처에서 다시 받을 수 있다.
- **법률 자문이 아니다.** 이 자료로 만든 판정은 검토 보조이며 최종 판단은 담당자·전문가가 한다.

## 넣지 않은 것

- 가이드라인 F1(명칭), F2(제조방법), F3(의약부외품 효능 범위), F6.0–F6.1, E1, E10–E13, E16, E17, E19, E21, 자료편(제4장) — 우리 제품(스킨·에센스, 제품 구분 미정)과 관련이 적다. F3은 의약부외품으로 정해지면 추가한다.
- 薬機法 제67·68조 — 화장품에 적용되지 않는다.
- 일본 개인정보보호법(APPI), 특정전자메일법 — 알림받기·설문의 개인정보 수집에 필요. 아직 자료 없음.
