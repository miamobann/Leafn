## 2. CSV 1개로 두 기능이 되는지 확인 (2026-10-26)

팀 Qoo10 수집 CSV(`qoo10_ranking_top20_excel.csv`, 化粧水 20개, 열 17개)를 앱의 실제 읽기 코드 두 개에 그대로 넣어 봤다.

| 읽기 코드 | 결과 |
| --- | --- |
| 랭킹 (`lib/external/qoo10-ranking-csv.ts`) | **20개 모두 읽힘.** 정가·할인가·쿠폰가·상품URL 20개, 용량은 상품명에서 14개 (세트 6개는 비움) |
| 경쟁제품 (`lib/external/competitor-csv.ts`) | **20개 모두 읽힘, 건너뛴 줄 0.** 브랜드·상품명·상품코드·정가·전성분·핵심 성분 |

→ **같은 파일 하나를 두 곳에 올리면 된다.** 랭킹은 카테고리마다 따로 올린다 (지금 파일은 化粧水). 주마다 수집 날짜를 다르게 올리면 순위 변화가 쌓인다.

**함께 발견한 문제**

1. **전성분 쉼표 잘림 (코드 문제, 20개 전부):** 경쟁제품 읽기 코드가 쉼표마다 자른다. 그래서 `グルタチオン(3,000ppm)`은 `グルタチオン(3` · `000ppm)`으로, `1,2-ヘキサンジオール`은 `1` · `2-ヘキサンジオール`로 나뉜다. 성분 비교는 이름 일부로 찾아서 대부분 맞지만, 성분 수와 전성분 표시가 틀린다. → **숫자 사이 쉼표는 자르지 않게** 고친다 (4장 1번).
2. **수집 데이터 확인 필요 (CSV 문제):**
   - 18위(トゥヴェール 바리어샷 로션)의 전성분·핵심 성분이 12위(같은 브랜드 GA 로션)와 글자까지 같다.
   - 19위(スキンアンドラブ TX 나이아신 토너)는 1위(글루타티온 토너)와 같다. 서로 다른 제품이라 복사 실수로 보인다.
   - 2위 전성분에 `パン테놀`처럼 한글이 섞여 있다.
   - 수집 담당자에게 다시 확인을 부탁한다.

## 3. 키 (환경 변수) — 팀장님 확인 요청

API 키는 DB가 아니라 **Vercel 환경 변수**에 들어간다 (CLAUDE.md 9장. 넣는 사람은 총괄).

| 키 | 쓰는 버튼 | 요청 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 검색 추천어 번역, GEO, SNS 니즈, 1:1 비교 한국어 해석 | **Vercel에 있는지 확인 부탁드립니다** |
| `SERPAPI_API_KEY` | 검색 추천어, 성분 검색 관심도 | **Vercel에 있는지 확인 부탁드립니다** |
| `APIFY_TOKEN` | SNS 핵심 니즈 | **없을 것으로 보여 추가 부탁드립니다** (값은 따로 전달) |
| `ANTHROPIC_API_KEY` | (GEO의 Claude 측정) | **넣지 않는다.** 없으면 GEO는 Claude를 건너뛰고 ChatGPT만 측정한다 (오류 없음, `lib/ai/geo/engines.ts`의 `available()`) |

- 위 두 키가 이미 있으면 → `APIFY_TOKEN` 하나만 추가하면 된다.
- 없으면 → 최종 계획안에서 `OPENAI_API_KEY`·`SERPAPI_API_KEY`도 추가 요청에 넣는다.
