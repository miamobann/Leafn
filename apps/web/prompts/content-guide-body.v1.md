# 7. 이번 작업: 고른 제목으로 본문

user 메시지 끝의 `[고른 제목]` 을 그대로 살려, 그 채널의 **본문 블록 전체**를 만든다.

```
[고른 제목]
일본어: <title_ja>
한국어: <title_ko>
각도: <angle>
```

- 블록 키와 순서는 3장 01의 채널 규칙을 따른다.
  - 상세페이지(큐텐): `hook` `proof` `concern` `routine` `hero` `points` `ingredient` `texture` `howto` `review` `lineup` `info` (12장) + 대표 이미지 5장(`gallery`)
  - 인스타그램: `caption` → `slide1` … `slideN` (N = 사진 장수)
  - X: `post` → `image`
  - 배너: `copy` → `sub`
- 고른 제목은 첫 블록(상세 `hook` · 인스타 `caption` 첫 줄과 `slide1` · X `post` 첫 줄 · 배너 `copy`)에 그대로 쓴다.
- 블록마다 `options` 는 1~2개: 첫 번째가 가장 추천, 두 번째는 다른 안(선택).
- 사진이 들어가는 블록은 `image` 에 촬영 지시를 한국어로 쓴다 (3장 04: 컷 종류 · 구도 · 배경 · 비율). 사진이 없으면 `null`.
- 근거가 필요한 블록(상세 `proof`)은 입력 `[근거 자료]` 가 없으면 `options` 를 `[{"text_ja": "", "text_ko": "(어떤 근거가 있으면 무엇을 쓸 수 있는지)"}]`, `needs_evidence: true` 로 둔다.
- 리뷰가 있어야 하는 블록(상세 `review`)은 `needs_reviews: true`. 출시 상태가 developing이면 만들지 않는다. **후기는 지어내지 않는다.** 입력 `[리뷰 원문]` 의 실제 리뷰만 일본어로 옮긴다 (뜻을 바꾸거나 과장하지 않음). 원문에 약기법에 걸리는 말(치료·자극 없음·기간 효과 등)이 있으면 그 리뷰는 쓰지 않는다. 리뷰는 말풍선 하나씩 한 줄(「…」)로, 첫 번째 안 하나에 모두 담는다. 「재구매」는 「リピート」처럼 뜻 그대로 옮긴다. 흡수가 빠르다는 말(금방 흡수)은 「すっとなじむ」처럼 사용감으로 옮기고 「すぐに」를 쓰지 않는다. 마지막 줄에 「※個人の感想です」를 붙인다. `[리뷰 원문]` 이 「없음」이면 `options` 를 `[{"text_ja": "", "text_ko": "(리뷰 원문이 있으면 채워요)"}]` 로 둔다.
- 해시태그(인스타·X만): 인스타는 브랜드 2(영문·가타카나 한 쌍: #LeafAnd #リーフアンド) · 성분·제형 1 · 고민·트렌드 1 (검색어 태그 1개는 코드가 붙인다). X는 브랜드 1 · 캠페인/제품 1. 상세페이지·배너는 빈 배열.
- 제품명 자리는 `{product}`, 성분 목록 자리는 `{ingredients_ja}` 로 둔다. 코드가 실제 값으로 바꾼다.
- X 게시글은 해시태그를 포함해 130자 이내.
- 게시물 종류가 `mega_sale` 이면 `[행사]` 의 행사명·기간을 첫 블록(캡션·게시글 첫 부분)에 넣고, 세일 내용은 「セール内容はQoo10公式ページをご確認ください」로 안내한다. `[행사]` 가 「없음」이면 날짜를 쓰지 않는다.
- 훅·특장점에도 「長時間」「うるおいが続く時間」 같은 지속 표현을 쓰지 않는다. 「しっとり」「うるおう」처럼 사용감으로 쓴다.

# 8. 출력 형식

JSON 하나만 출력한다. 설명 문장을 앞뒤에 붙이지 않는다.

```json
{
  "blocks": [
    {
      "key": "블록 키",
      "heading": "블록 이름 (한국어)",
      "options": [
        { "text_ja": "가장 추천 문구", "text_ko": "번역" },
        { "text_ja": "다른 안 (선택)", "text_ko": "번역" }
      ],
      "reason": "첫 번째 안을 추천하는 이유 (한국어 1문장)",
      "image": "촬영 지시 (한국어) 또는 null",
      "needs_reviews": false,
      "needs_evidence": false
    }
  ],
  "hashtags": { "brand": ["#LeafAnd"], "ingredient": ["#ヒアルロン酸"], "trend": ["#乾燥肌", "#保湿ケア"] },
  "gallery": [
    { "role": "대표 (검색 썸네일)", "image": "제품 단독 정면 컷 · 흰색 배경 · 제품이 화면의 70~80%", "rules": ["글자는 브랜드·제품명 정도만"] }
  ]
}
```

- `gallery` 는 상세페이지(큐텐)만 5장(역할 순서는 3장 01), 그 밖의 채널은 빈 배열. `rules` 는 첫 장만.
